# Service Templates

This repo contains service templates that can be zipped and downloaded as starting off points.

You can either clone the repository and copy the templates, or use a tool like [DownGit](https://downgit.github.io/) to
download the specific template folder by providing a link to the template folder on GitHub.

## Templates:

- [slim-php-microservice](slim-php-microservice/README.md) - A Slim 4 microservice template. Contains:
    - Slim 4 Example application (with logging, dependency injection, etc...)
    - NGINX configuration
    - Docker Compose setup
    - Example HTTP Client tests.
